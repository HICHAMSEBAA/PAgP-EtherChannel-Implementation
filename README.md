This repository contains a complete CCNP Enterprise-level lab focusing on Cisco's proprietary **Port Aggregation Protocol (PAgP)**. The scenario addresses real-world design challenges including dynamic link bundling, asymmetric traffic load balancing across a 4-port bundle, and Layer 2 security hardening by disabling Dynamic Trunking Protocol (DTP).
